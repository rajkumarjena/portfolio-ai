Database Backup and Refresh

Admin only. Starting a backup or a refresh briefly pauses the whole application (BACKUP.md): every user — signed in or not — sees a red warning banner across the top of their page, new requests are held for a few seconds so pending work can finish, the process runs, then the banner disappears by itself.

Database Backup

Creates a consistent snapshot of the live server database portfolio.db and downloads it to this computer.

File: portfolio.db → saved as portfolio-backup-<date>.db

Database Refresh

Replaces the server's database with a portfolio.db file from this computer. All current server data becomes the data of the uploaded file; the previous file is kept on the server as portfolio.db.before-refresh.

Application Log

Downloads the server's application log (springboot.log) and clears it on the server afterwards (back to 0 bytes). No warning banner is shown for this process.
