Bond SIP

Set up a systematic bond investment (BONDBP_V7). Instalments are generated automatically per the selected Frequency (weekly to yearly, like a bond's coupon frequency) - a past SIP date is backfilled with every instalment already due, each one waiting on the Bond SIP Transactions screen for the actual amount and the bond to associate.

How it works

  • The Issuer drop-down lists the issuers configured in Application Parameter Configuration (param name: issuer), refreshed from the App Config object every 15 minutes. SIP Date, SIP Amount and Frequency are mandatory; Create Date is stamped to today.
  • Status starts as CREATED and is never editable (#3); it turns INPROGRESS once the first instalment is generated.
  • One Bond SIP Transaction record is auto-created per due instalment of the frequency schedule - entering a past SIP date backfills every instalment due so far; weekend dates roll to the next weekday (#4).
  • On the transaction screen you enter the Actual SIP Amount and pick the bond (Bond Name|PAN, own or family) per instalment - that transaction then turns EXECUTED (#5-#7).
