Database Query

Admin only (ADMIN_V1). Run a supported SQL statement against the server database and see the outcome here. A successful DQL query (SELECT / VALUES) downloads its complete result as a CSV file — column names as the header row, every returned data row below. DML, DDL and TCL statements just report Status: Success, and a failing query shows its database error on this screen so you can correct it and retry.

How it works

  • Pick the category first: it validates the statement you typed (a DELETE under DQL is rejected before it runs).
  • DQL (SELECT, VALUES) returns the complete result set as a CSV download with the column names on the first row.
  • DML (INSERT, UPDATE, DELETE, REPLACE), DDL (CREATE, DROP, ALTER, VACUUM) and TCL (BEGIN, COMMIT, ROLLBACK, SAVEPOINT) report success without a file.
  • Empty queries never run; a failing query shows the actual database error on this screen for a retry. Every execution is audit-logged with your user, the SQL and the outcome, with a statement timeout and a maximum result size in force.
